# Motion review checklist

- Is the animation necessary?
- Does it explain a state change?
- Is the duration proportional to distance?
- Does entering motion decelerate naturally?
- Is exit motion concise?
- Are transform/opacity used where practical?
- Is there any flash, jump, or reflow?
- Can repeated clicks break the animation?
- Does it work on touch devices?
- Does reduced motion remain usable?
