# Water Tech UI QA checklist

## Layout
- [ ] No horizontal overflow
- [ ] No clipping or overlap
- [ ] Consistent container alignment
- [ ] Consistent vertical rhythm

## Typography
- [ ] Heading hierarchy is clear
- [ ] Body text remains readable
- [ ] No awkward line breaks at tested widths

## Components
- [ ] Buttons consistent
- [ ] Cards consistent
- [ ] Forms aligned
- [ ] Icons aligned
- [ ] Interactive states visible

## Responsive
- [ ] Narrow mobile
- [ ] Standard mobile
- [ ] Tablet
- [ ] Desktop

## Technical
- [ ] Build/dev server succeeds
- [ ] No new runtime errors
- [ ] Assets load
- [ ] Relevant routes work

## Motion
- [ ] No flicker/jump
- [ ] Timing feels responsive
- [ ] Reduced motion considered
